# План устранения проблемы отсутствия лог-файла laya_requests.jsonl на 192.168.50.38

## Причина проблемы
1. `LayaAuditLogger` в `logger.py` при инициализации создавал только директорию `~/.hermes/logs/`, но не создавал сам файл `laya_requests.jsonl` до первой фактической записи. Поэтому при запуске `tail -f` до первого обработанного запроса утилита `tail` падала с `Нет такого файла или каталога`.
2. В `__init__.py` хук `pre_llm_call` в runtime Hermes вызывался из вспомогательного фонового потока (daemon thread), где `agent` не передается в `kwargs`, а фреймы потока изолированы от основного потока сессии. При отсутствии ссылки на `agent` вызов тихо возвращал `None`, пропуская оценку Laya.
3. Долгоживущий сервис Hermes Gateway (`hermes-gateway.service`) был запущен ранее и требовал перезапуска для гарантированного подхвата обновлений плагина.
